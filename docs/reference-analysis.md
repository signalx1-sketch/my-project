## A그룹 공통 패턴 (자동화 대상)

### 1. 콜드 오픈 티저 (3/3)
- 본문 중 가장 자극적인 발언을 **0:00에 15~30초** 먼저 보여준 뒤 인트로로 넘어간다.
  - 성현철: 0:00–0:30 핵심 주장 몽타주 → 0:30 타이틀 범퍼
  - 묘한의사: 0:00–0:17 본문 클립을 그대로 재사용, 블러 배경 + 안쪽 16:9 창 → 효과음 → "안녕하세요"
  - 손현호: 결론부 멘트를 맨 앞에 배치, 핵심 단어를 삐- 처리해서 궁금증 유발
- 티저는 **반전, 상식 뒤집기** 문장이다 ("보습제를 많이 바르면 재생이 안 된다", "턱끝, 여기는 제 와이프도 맞아요").

### 2. 무음 제거 + 펀치인 줌
- 문장 사이 숨소리와 공백을 거의 0ms로 잘라낸다 (6/6 공통).
- 카메라 1대로 컷마다 **100% ↔ 110~120% 디지털 줌**을 번갈아 준다 (성현철, 묘한의사, 닥터펠프스).
- 평균 컷 길이는 2.5~5초, 훅 구간은 1.5~3초.

### 3. 자막
- 하단 중앙, 한 줄, **4~8어절**
- 흰 글자 + 얇은 외곽선/그림자 (또는 반투명 둥근 박스)
- 핵심 단어 **노란색 강조** (#FFD200~#FFE600)
- 펀치라인은 화면 중앙에 큰 팝업 텍스트로
- 이모지는 거의 쓰지 않음 (의료 톤)

### 4. 고정 오버레이
- 좌상단(또는 우상단)에 **현재 챕터 라벨** 고정 ("Q. 동안 보톡스 부위 TOP 3", "주사피부염의 원인: 과민한 면역 반응")
- 반대쪽 모서리에 채널 로고
- 챕터 전환 시 "Q." 타이틀 카드 1~2초

### 5. 사운드
- BGM은 대사보다 약 -20~-24dB 낮게, 말할 때 덕킹
- 효과음: 줌/전환에 휙(whoosh), 텍스트 등장에 팝(pop), 순위·핵심 포인트에 딩(ding)

### 6. 구성과 엔딩
- 순위형(TOP 3→1), Q&A형 챕터 구조
- 구독 CTA 후 **쿠키 영상**(비하인드, NG) 또는 오프닝 멘트를 다시 보여주며 마무리

## A그룹 vs B그룹 차이 (가설)

| 항목 | A (조회수 높음) | B (조회수 낮음) |
|---|---|---|
| 첫 장면 | **의사 본인 얼굴과 목소리**로 반전 발언 | 검정 텍스트 카드, 스톡 B-roll, "preview" 몽타주 |
| 화면 비중 | 대부분 얼굴, 그림은 보조 | 풀스크린 슬라이드, 스톡 영상 비중 큼 |

→ 편집 공수가 더 많이 들어간 B그룹(더마허브)이 구독자 대비로도 성과가 낮다. **화려한 그래픽보다 "얼굴 + 반전 훅 + 빠른 템포"** 가 핵심이라는 가설을 세울 수 있다. (표본 6개라 상관관계 수준의 추론이다.)

## 자동 편집기에 넣을 기능 (우선순위)

1. **무음/필러 제거:** 음성 인식 단어 타임스탬프 기반
2. **자동 자막:** 한국어 음성 인식, 한 줄 4~8어절, 핵심어 노란색 강조
3. **펀치인 줌:** 컷마다 100%/115% 교대
4. **콜드 오픈 자동 생성:** 대본에서 가장 강한 훅 문장 1~3개를 골라 앞에 배치
5. **챕터 라벨:** 대본 주제 전환을 감지해 좌상단 "Q. …" 표시
6. **BGM 덕킹 + 효과음:** 컷/텍스트 이벤트에 자동 배치
7. (선택) 로고 워터마크, 엔딩 CTA, 쿠키 영상 슬롯
