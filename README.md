# 더마허브 자동 편집기

의사 1인 토크 원본 영상을 넣으면 조회수 높은 피부과 채널들의 편집 패턴을 적용한 결과물을 만듭니다.
레퍼런스 분석은 [docs/reference-analysis.md](docs/reference-analysis.md)에 있습니다.

## 자동으로 들어가는 것

| 기능 | 내용 |
|---|---|
| 무음/군말 제거 | 실제 음량 기준 0.4초 넘는 무음과 단독 "어", "음"을 잘라냄 |
| 콜드 오픈 | 본편에서 가장 센 문장 1~3개를 맨 앞에 붙이고, 제목 범퍼(1.4초)로 넘어감 |
| 펀치인 줌 | 2.5~4.5초마다 문장 경계에서 100% ↔ 115% 교대, 콜드 오픈은 1.5~3초마다 112% ↔ 126% |
| 자막 | 하단 중앙 한 줄, 15자/6어절 이내, 흰 글자 + 검은 테두리, 핵심 단어 노란색, 잘못 인식된 약 이름 교정 |
| 챕터 | 주제 시작 때 화면 중앙에 "Q. 주제" 크게, 그 뒤로 좌상단에 계속 표시 |
| 로고 | 우상단 채널명 |
| 효과음 | 화면 전환 휙, 강조 자막 팝, 마지막 구독 안내 딩 (직접 합성, 저작권 없음) |
| 배경음악 | `--bgm`으로 주면 대사 아래 작게 깔고 말할 때 자동으로 줄임 |
| 음량 | 유튜브 기준 -14 LUFS로 맞춤 |

## 설치 (처음 한 번)

1. [Python 3.10 이상](https://www.python.org/downloads/)과 [ffmpeg](https://ffmpeg.org/download.html)를 설치합니다.
2. 이 폴더에서:
   ```
   pip install -r requirements.txt
   ```
3. (선택) Claude가 콜드 오픈/챕터/강조 단어를 고르게 하려면 `.env.example`을 `.env`로 복사하고 API 키를 넣습니다.
   키가 없으면 콜드 오픈만 키워드 규칙으로 고르고 챕터/강조는 생략합니다.

## 사용법

```
python -m autoedit 원본.mp4
```

결과는 `원본_편집.mp4`로 나옵니다. 중간 파일은 `원본_work/` 폴더에 남습니다.

| 옵션 | 설명 |
|---|---|
| `-o 결과.mp4` | 결과 파일 이름 |
| `--plan 계획.json` | 편집 계획을 직접 지정 (아래 참고) |
| `--bgm 음악.mp3` | 배경음악 |
| `--channel 이름` | 우상단 로고 글자 (기본: 더마허브) |
| `--no-ai` | Claude API를 쓰지 않음 |

### 편집 계획 고치기

처음 실행하면 `원본_work/sentences.txt`(번호 붙은 문장 목록)와 `원본_work/plan.json`이 생깁니다.
`plan.json`을 고친 뒤 `--plan`으로 다시 돌리면, 음성 인식은 건너뛰고 바뀐 부분만 다시 만듭니다.

```json
{
  "title": "스테로이드 대신 이 약",
  "hooks": [{"from": 12, "to": 13}],
  "chapters": [{"from": 0, "label": "스테로이드 악순환"}],
  "keywords": ["프로토픽", "엘리델"],
  "fix": {"디페린결": "디페린겔", "캐토코나졸": "케토코나졸"},
  "skip": [{"from": 5, "to": 5}]
}
```

- `hooks`: 맨 앞에 붙일 문장 번호 구간
- `chapters`: 주제가 시작되는 문장 번호와 라벨
- `keywords`: 자막에서 노란색으로 칠할 단어 (자주 나오는 단어는 빼야 강조 효과가 삽니다)
- `fix`: 음성 인식이 틀린 표기 → 올바른 표기 (약 이름은 꼭 확인하세요)
- `skip`: 본편에서 뺄 문장 (NG 등)

실제 예시: [examples/스테로이드_말고_이거_달라고_하세요.plan.json](examples/스테로이드_말고_이거_달라고_하세요.plan.json)

## 처리 시간 (참고)

9분 원본 기준, CPU 4코어에서 음성 인식 약 10분 + 렌더링 약 12분.
두 번째 실행부터는 음성 인식과 바뀌지 않은 클립을 다시 하지 않습니다.
