# 가온 워드

브라우저에서 바로 쓰는 MS Word 호환 워드 프로세서입니다. 설치할 것은 없습니다.

## PC에서 열기

- **`gaon-word-offline.html`** (권장): 받아서 더블클릭하면 됩니다. 인터넷이 없어도 모든 기능이 동작합니다. 글꼴은 PC에 설치된 것(Windows는 맑은 고딕, 바탕, 굴림, 돋움 등)을 씁니다.
- `index.html`: 인터넷에서 압축 도구와 웹 글꼴(나눔고딕, Noto 등)을 불러오는 버전입니다.

## 할 수 있는 일

- **.docx 열기**: Word 문서를 열어 편집 (열기 버튼, Ctrl+O, 또는 파일을 페이지 위로 끌어다 놓기)
- **.docx로 저장**: Microsoft Word, 한컴오피스, LibreOffice, Google Docs에서 열리는 파일로 저장 (Ctrl+S)
- HTML·텍스트 파일 열기/저장
- 서식: 제목 1–4, 인용, 글꼴, 글자 크기, 굵게/기울임/밑줄/취소선, 위·아래 첨자, 글자 색, 형광펜
- 문단: 정렬 4종, 줄 간격, 들여쓰기, 글머리 기호·번호 목록(여러 단계)
- 표(행·열 추가/삭제, 병합된 셀 유지), 그림(너비 조절), 링크, 페이지 나누기
- 찾기 및 바꾸기 (Ctrl+F)
- 편집 내용 자동 보관 (브라우저에 저장)

## .docx 호환 범위

| 항목 | 열기 | 저장 |
| --- | --- | --- |
| 제목 스타일, 굵게/기울임/밑줄/취소선, 첨자 | ✓ | ✓ |
| 글꼴, 크기, 글자 색, 형광펜·음영 | ✓ | ✓ |
| 정렬, 줄 간격, 문단 앞뒤 간격, 들여쓰기 | ✓ | ✓ |
| 글머리 기호·번호 목록 (중첩 포함) | ✓ | ✓ |
| 표 (가로·세로 병합, 셀 배경색, 머리글 행) | ✓ | ✓ |
| 그림 (PNG/JPEG/GIF, 그 외 형식은 PNG로 변환) | ✓ | ✓ |
| 하이퍼링크, 페이지 나누기 | ✓ | ✓ |
| 머리글/바닥글, 각주, 변경 내용 추적, 주석, 도형 | 무시됨 | – |
| 이전 형식 `.doc` | 지원 안 함 (Word에서 .docx로 저장 후 열기) | – |

## 구조

- `src/gaon-word.html` – 앱 전체 (HTML, CSS, JS 한 파일). .docx 읽기/쓰기는 직접 구현했고, 압축 처리에만 [JSZip](https://stuk.github.io/jszip/)을 CDN으로 불러옵니다.
- `vendor/jszip.min.js` – 오프라인 버전에 넣는 JSZip 3.10.1 (MIT 라이선스)
- `build.sh` – `src/gaon-word.html`로 `index.html`과 `gaon-word-offline.html`을 만듭니다. 소스를 고친 뒤 실행하세요.
