# 비포앤애프터 사진

질환별 폴더에 같은 번호로 전·후 사진을 넣으면, 쇼츠 중간에 "실제 치료 전·후" 카드로 약 3초간 들어갑니다.

```
아토피/01_before.jpg
아토피/01_after.jpg
아토피/01.txt        (선택) 카드 아래 설명, 예: 치료 6개월
```

- `_전` / `_후` 이름도 됩니다.
- 사진 파일은 git에 올라가지 않습니다 (.gitignore). 구글 드라이브 `비포앤애프터` 폴더와 같은 구조입니다.
- 환자 동의를 받은 사진만 쓰고, 게시 전 의료광고 규정(의료법 제56조)을 확인하세요.
- 쇼츠 계획(`ShortPlan.inserts`)에 `{"category": "아토피", "at": 원본 기준 초, "duration": 3}` 을 넣으면 그 시점에 카드가 나옵니다. 사진이 아직 없으면 회색 자리 표시 카드가 들어갑니다.
